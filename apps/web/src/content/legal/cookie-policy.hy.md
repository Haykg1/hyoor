## 1. Ի՞նչ են cookie-ները

Cookie-ները փոքր տեքստային ֆայլեր են, որոնք կայքը պահում է ձեր սարքում։ Նման
տեխնոլոգիաներ են նաև բրաուզերի `localStorage` / `sessionStorage`-ը՝ դրանք մնում են
սարքում և ամեն HTTP հարցման հետ չեն ուղարկվում այնպես, ինչպես cookie-ները։

ԵՄ/ԵՏՏ ePrivacy կանոնների և Հայաստանին ուղղված ծառայությունների լավ պրակտիկայի
համաձայն՝ **խիստ անհրաժեշտ** cookie-ները կարող են օգտագործվել առանց նախնական
համաձայնության։ **Ոչ անհրաժեշտ** cookie-ները (վերլուծություն, գովազդ) պահանջում են
նախնական համաձայնություն (opt-in)։ Մենք ներկայումս **չենք** բեռնում վերլուծական կամ
գովազդային cookie-ներ։

## 2. Ինչպես ենք օգտագործում cookie-ները այսօր

### 2.1 Խիստ անհրաժեշտ cookie-ներ

Անհրաժեշտ են կայքի անվտանգ աշխատանքի (մուտք) կամ cookie ընտրությունը հիշելու համար։
Միշտ միացված են։

| Անուն                     | Տեսակ                          | Նպատակ                                        | Տևողություն   |
| ------------------------- | ------------------------------ | --------------------------------------------- | ------------- |
| `rentstar_access_token`   | First-party cookie             | Կարճատև access token՝ API հարցումների համար   | 15 րոպե       |
| `rentstar_refresh_token`  | First-party cookie             | Երկարացնում է սեսիան առանց կրկին մուտքի       | 7 օր          |
| `rentstar_cookie_consent` | First-party cookie             | Պահում է cookie կատեգորիաների ընտրությունը    | 1 տարի        |
| `NEXT_LOCALE`             | First-party cookie (next-intl) | Հիշում է ընտրված լեզուն (`en`, `hy` կամ `ru`) | մինչև ~1 տարի |

Auth cookie-ները դրվում են միայն մուտքից (կամ OAuth-ից) հետո։ Օգտագործում են
`SameSite=Lax` և HTTPS-ում `Secure` դրոշը։

### 2.2 Նախընտրությունների պահեստ սարքում

Սրանք մուտքի cookie չեն։ Դրանք հարմարավետության համար են և սովորաբար մնում են միայն
ձեր սարքում՝

| Բանալի / տեխնոլոգիա                            | Նպատակ                                |
| ---------------------------------------------- | ------------------------------------- |
| Թեմա (`next-themes` / local storage)           | Լուսավոր / մուգ / համակարգային տեսք   |
| `hyoor-host-display-currency` (local storage)  | Գների ցուցադրման արժույթ              |
| Հայտարարության wizard սևագիր (session storage) | Ժամանակավոր սևագիր ստեղծման ընթացքում |
| AI չատի սևագրեր (session/local storage)        | Չատի ժամանակավոր վիճակ                |
| Փոքր UI դրոշներ (local storage)                | օր. ծանուցումը թաքցնելը               |

Եթե ընտրում եք **Միայն անհրաժեշտը**, մենք ընտրովի նախընտրությունների պահպանումը
համարում ենք մերժված ապագա ոչ անհրաժեշտ նպատակների համար։ Հիմնական դիտումն ու մուտքը
աշխատում են։ Ձեր ընտրած լեզուն կարող է դնել `NEXT_LOCALE`, քանի որ դա պետք է էջը
պահանջված լեզվով տալու համար։

### 2.3 Վերլուծություն և գովազդ

Ներկայումս մենք **չենք** օգտագործում վերլուծության, գովազդի կամ սոցիալական
փիքսելների cookie-ներ։

Եթե հետո ավելացնենք վերլուծություն, մենք՝

1. կթարմացնենք այս Cookie քաղաքականությունը և Գաղտնիության քաղաքականությունը․
2. կբեռնենք սկրիպտները **միայն** եթե համաձայնել եք **Վերլուծություն** կատեգորիային․
3. չենք վաճառի ձեր անձնական տվյալները որպես կայքից օգտվելու պայման։

## 3. Ձեր ընտրությունը

Առաջին այցելության ժամանակ պաստառը թույլ է տալիս՝

- **Ընդունել բոլորը** — անհրաժեշտ + նախընտրություններ + վերլուծություն (վերլուծությունը
  չի օգտագործվում, մինչև իրականում չմիացնենք սկրիպտներ)․
- **Միայն անհրաժեշտը** — միայն խիստ անհրաժեշտ cookie-ներ․
- **Կարգավորել** — միացնել/անջատել Նախընտրություններն ու Վերլուծությունը և պահպանել։

Երկխոսությունը կրկին բացելու համար օգտագործեք **Cookie կարգավորումներ** կայքի
footer-ում։

### 3.1 Cookie-ների կառավարումը բրաուզերում

Տարբեր բրաուզերներ առաջարկում են կայքերի cookie-ները արգելափակելու և ջնջելու տարբեր
եղանակներ։ Կարող եք ցանկացած պահի փոխել բրաուզերի կարգավորումները՝ cookie-ները
արգելափակելու կամ ջնջելու համար։ Հանրահայտ բրաուզերների պաշտոնական ուղեցույցները՝

- [Google Chrome](https://support.google.com/chrome/answer/95647)
- [Apple Safari](https://support.apple.com/guide/safari/manage-cookies-sfri11471/mac)
- [Mozilla Firefox](https://support.mozilla.org/kb/clear-cookies-and-site-data-firefox)
- [Microsoft Edge](https://support.microsoft.com/microsoft-edge/delete-cookies-in-microsoft-edge-63947406-40ac-c3b8-57b9-2a946a29ae09)

Այլ բրաուզեր օգտագործելու դեպքում դիմեք դրա պաշտոնական աջակցության փաստաթղթերին։

Նկատի ունեցեք՝ auth cookie-ների ջնջումը կավարտի սեսիան, իսկ `rentstar_cookie_consent`-ի
ջնջումը կրկին կցուցադրի համաձայնության պաստառը։ Խիստ անհրաժեշտ cookie-ների
արգելափակումը կարող է խաթարել կայքի որոշ մասերի (օրինակ՝ մուտքի) աշխատանքը։

## 4. Երրորդ կողմեր

Մենք ներկայումս չենք միացնում երրորդ կողմի մարքեթինգային թրեքերներ։ Առցանց քարտային
վճարումը դեռ հասանելի չէ [WEBSITE NAME]-ում. եթե ապագայում ներդնենք երրորդ կողմի վճարային
մշակող, այս քաղաքականությունը կթարմացվի՝ նկարագրելու համար դրա cookie-ները։

## 5. Այլ երկրների օգտատերեր

Եթե մուտք եք գործում ԵՄ/ԵՏՏ/Մեծ Բրիտանիայից, այս քաղաքականությունը նախատեսված է
ePrivacy-ի թափանցիկության և համաձայնության ակնկալիքներին և GDPR-ի թափանցիկության
սկզբունքներին համապատասխանելու համար՝ ինչպես նկարագրված է Գաղտնիության
քաղաքականությունում։

## 6. Փոփոխություններ

Մենք կարող ենք թարմացնել Cookie քաղաքականությունը տեխնոլոգիաների փոփոխության դեպքում։
«Վերջին թարմացում» ամսաթիվը կփոխվի։ Նոր ոչ անհրաժեշտ cookie-ների էական
փոփոխությունների դեպքում կրկին կհարցնենք համաձայնություն, որտեղ պահանջվում է
(օրինակ՝ բարձրացնելով համաձայնության տարբերակը)։
